### 主な部品・機材

| 分類 | 部品・機材 | 型番・仕様 | 用途 |
| --- | --- | --- | --- |
| センサー | ピエゾシリンダー | JLI-PZ001 | 水中の振動を電気信号へ変換 |
| バッファー | P48 Hi-Z Piezo Buffer | P48対応 | ピエゾ素子の高インピーダンス信号を受ける |
| オペアンプ | Texas Instruments OPA1642 | OPA1642AIDR | 低ノイズ信号処理 |
| コネクター | XLRオス／メス | NC3MXX／NC3FXX | バランス接続 |
| ケーブル | BELDEN 8142、MOGAMI 2534 | 2芯／2芯バランス | センサー信号の伝送 |
| 防水・成形材 | レジン、シリコン、銅板、PLA | — | センサー部の封止、保護、筐体製作 |
| 録音機器 | ZOOM H1essential | 32-bit Float、最大96 kHz | 試験録音・フィールドレコーディング |

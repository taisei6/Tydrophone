# Tydrophone

DIY Hydrophone Project

## 部品リスト

| 部品 | 数量 | 用途・備考 |
| --- | ---: | --- |
| 圧電素子（ピエゾディスク） | 1 | 水中の振動を電気信号に変換するセンサー |
| シールドケーブル | 必要な長さ | センサー信号を伝送し、外来ノイズを抑える |
| 3.5 mmモノラルプラグ | 1 | 録音機器やアンプへの接続用。使用機器に合わせて変更可 |
| 防水ケースまたはキャップ | 1 | 圧電素子と配線接続部の保護 |
| エポキシ樹脂 | 適量 | センサー部の封止・防水 |
| 熱収縮チューブ | 適量 | 配線接続部の絶縁と保護 |
| はんだ | 適量 | 圧電素子、ケーブル、プラグの接続 |
| プリアンプ | 1（任意） | 信号が小さい場合の増幅用 |

> [!NOTE]
> コネクターの種類やプリアンプの有無は、接続する録音機器の入力仕様に合わせて選定してください。
